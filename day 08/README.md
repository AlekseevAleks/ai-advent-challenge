# Чат с LLM

Локальный сервис для общения с LLM через OpenAI-совместимый API. Несколько агентов, у каждого — свой чат с историей и выбор модели.

## Возможности

- **Агенты** — именованные сущности, каждая ведёт собственную переписку с LLM (история сохраняется между сообщениями).
- **Сайдбар слева** — список агентов, кнопка «＋ Новый», удаление через диалог подтверждения («Да»/«Нет»).
- **Создание агента** — диалог с полями «Имя агента», «Модель LLM» и «Лимит контекста» (подставляется из данных модели, можно изменить); модели загружаются с того же API-адреса (список из `/models`).
- **Чат** — история сообщений сверху, поле ввода внизу; ответ приходит с Markdown-форматированием.
- **Параметры агента** — правая панель: модель, лимит контекста и расход токенов за весь диалог.
- **Лимит контекста** — сколько токенов переписки уходит в каждый запрос; старые сообщения отбрасываются, если история не помещается.
- **Сохранение в SQLite** — агенты и вся переписка хранятся в локальной базе `agents.db` и восстанавливаются после перезапуска сервера; при удалении агента из базы удаляются и его сообщения.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откроется браузер на http://127.0.0.1:7860.

## Настройка подключения

Файл `api_key.txt` лежит рядом с `app.py` (в git не попадает, см. `.gitignore`):

- первая строка — url OpenAI-совместимого API (например, `https://api.openai.com/v1`);
- вторая строка — api-ключ.

Модель по умолчанию задаётся в `config.py` (`DEFAULT_MODEL`); она используется как начальный выбор в списке моделей.

## Структура

- `app.py` — точка входа: собирает конфиг, клиент, реестр агентов и запускает сервер;
- `config.py` — читает url и ключ из `api_key.txt`;
- `llm_client.py` — транспорт к API: список моделей и отправка переписки (`/chat/completions`);
- `agent.py` — агент: имя, модель, лимит контекста, собственная история чата, запросы к LLM с обрезкой истории под лимит;
- `agent_registry.py` — реестр агентов в памяти: создание, поиск, удаление, восстановление из базы при старте;
- `agent_store.py` — SQLite-хранилище: агенты и сообщения в `agents.db`;
- `ui.py` — интерфейс на Gradio: сайдбар агентов, чат, диалоги создания и удаления;
- `styles.py` — CSS: layout сайдбара, чата и модальных диалогов.
