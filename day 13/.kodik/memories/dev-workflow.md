# Рабочий процесс

## Запуск и остановка сервера

Запуск (порт 8005 по умолчанию):

```bash
cd "/Users/lexx/Documents/AI challenge/основа"
.venv/bin/python run.py --no-browser
```

**Всегда останавливать сервер после проверок** — пользователь просил не оставлять
его работающим в фоне:

```bash
pkill -f "run.py --no-browser"
```

Проверка, что порт освободился: `lsof -nP -iTCP:8005 -sTCP:LISTEN`.

## Данные пользователя

`data/` (config.json, chat.db) содержит реальные настройки, чаты, память,
профили и состояния задач. **Не удалять** при проверках — тесты используют
изолированную временную директорию (`tmp_path`), реальные данные им не нужны.

## Тесты

```bash
.venv/bin/python -m pytest
```

Фоновые задачи (анализ памяти, пересчёт состояния задачи) выполняются
асинхронно — в тестах ждать их через `fake_api.wait_for_analysis()`.

## Окружение

macOS: команды `pip` нет в PATH, использовать `.venv/bin/python -m pip`.
