# 🤖 AI Сервис — сравнение моделей

Веб-сервис на Python (Flask), который отправляет один и тот же вопрос к **трём выбранным моделям** через API [polza.ai](https://polza.ai), показывает три ответа в три столбца с метаданными (время, токены, стоимость), а затем просит ИИ сравнить ответы по качеству, скорости и ресурсоёмкости и дать вывод о различиях между моделями.

## Возможности

- При открытии страницы автоматически загружается список моделей с типом `chat` из API polza.
- Три поля выбора модели над полем ввода — можно выбрать любые три модели из списка.
- Три параллельных запроса к выбранным моделям при нажатии «Отправить».
- Ответы выводятся в три столбца; в начале каждого ответа — **время ответа**, **количество токенов** и **стоимость**.
- Отдельный запрос сравнивает ответы по критериям: **качество**, **скорость**, **ресурсоёмкость**.
- Короткий вывод о различиях между моделями + ссылки на сайты провайдеров.
- Ответы отображаются с поддержкой форматирования **Markdown** (заголовки, списки, код, таблицы, ссылки).

## Установка и запуск

### 1. Перейти в папку проекта

```bash
cd "day 04"
```

### 2. Создать виртуальное окружение (рекомендуется)

```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить API-ключ

Создайте файл `api_key.txt` в папке проекта. Первая строка — API-ключ, вторая — URL для подключения к API polza:

```
ВАШ_API_КЛЮЧ
https://polza.ai/api/v1
```

> ⚠️ Файл `api_key.txt` добавлен в `.gitignore` и не должен попадать в репозиторий.

### 5. Запустить сервер

```bash
python app.py
```

Сервис будет доступен по адресу: **http://localhost:5000**

Если порт 5000 занят (например, на macOS его занимает AirPlay Receiver), задайте другой:

```bash
PORT=5001 python app.py
```

## Как это работает

1. При открытии страницы сервер запрашивает у API polza список моделей с типом `chat` и передаёт его в интерфейс.
2. Пользователь выбирает три модели и вводит вопрос.
3. Сервер отправляет **три параллельных запроса** к выбранным моделям (эндпоинт `chat/completions`).
4. Для каждого ответа фиксируются метаданные:
   - **время ответа** — замеряется на сервере;
   - **количество токенов** — из `usage` (вход / выход / всего);
   - **стоимость** — из `usage.cost_rub`.
5. Ответы отображаются в трёх столбцах с метаданными в начале.
6. Сервер отправляет четвёртый запрос (первой выбранной моделью), в котором просит ИИ сравнить три ответа по критериям:
   - **качество** — насколько ответ полон, точен и полезен;
   - **скорость** — время ответа;
   - **ресурсоёмкость** — стоимость и количество токенов.
7. Итог выводится в блоке «Сравнение и рекомендации»: короткий вывод о различиях между моделями + ссылки на сайты провайдеров.

## API

### `GET /api/models`

Возвращает список моделей с типом `chat`:

```json
{
  "models": [
    {
      "id": "openai/gpt-5.4-mini",
      "name": "GPT-5.4 Mini",
      "context_length": 128000,
      "max_tokens": 32768,
      "prompt_per_million": 0.5,
      "completion_per_million": 1.5,
      "link": "https://openai.com"
    }
  ]
}
```

### `POST /api/chat`

Принимает JSON:

```json
{
  "message": "Текст вопроса",
  "models": ["openai/gpt-5.4-mini", "deepseek/deepseek-v4-flash", "google/gemini-3.6-flash"]
}
```

Возвращает:

```json
{
  "responses": [
    {
      "model": "openai/gpt-5.4-mini",
      "text": "...",
      "time_sec": 3.42,
      "tokens": 512,
      "prompt_tokens": 120,
      "completion_tokens": 392,
      "cost_rub": 0.0004
    }
  ],
  "comparison": "Сравнение и рекомендации..."
}
```

## Технологии

- **Python 3** + **Flask** — веб-сервер
- **requests** — HTTP-клиент для запросов к API polza
- **HTML / CSS / JavaScript** — интерфейс (marked + DOMPurify для рендеринга Markdown-ответов через CDN)
