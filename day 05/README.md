# 🤖 AI Сервис — сравнение настроек temperature

Веб-сервис на Python (Flask), который отправляет один и тот же вопрос к ИИ три раза — с разными значениями `temperature` (0, 0.7 и 1.2) — показывает три ответа в три столбца, а затем просит ИИ сравнить их по точности, креативности и разнообразию и дать рекомендации, для каких задач подходит каждая настройка.

## Возможности

- Поле ввода вопроса и кнопка «Отправить».
- Три параллельных запроса к ИИ с `temperature = 0`, `0.7`, `1.2`.
- Ответы выводятся в три столбца под кнопкой.
- Отдельный запрос сравнивает ответы по критериям: **точность**, **креативность**, **разнообразие**.
- Итоговая рекомендация: для каких задач лучше подходит каждая настройка.

## Установка и запуск

### 1. Клонировать и перейти в папку проекта

```bash
cd "day 04"
```

### 2. Создать виртуальное окружение (рекомендуется)

```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить API-ключ

Создайте файл `api_key.txt` в папке проекта. Первая строка — API-ключ, вторая — URL для подключения к OpenAI-совместимому API:

```
ВАШ_API_КЛЮЧ
https://polza.ai/api/v1
```

> ⚠️ Файл `api_key.txt` добавлен в `.gitignore` и не должен попадать в репозиторий.

### 5. Запустить сервер

```bash
python app.py
```

Сервис будет доступен по адресу: **http://localhost:5000**

Если порт 5000 занят (например, на macOS его занимает AirPlay Receiver), задайте другой:

```bash
PORT=5001 python app.py
```

## Как это работает

1. Пользователь вводит вопрос и нажимает «Отправить».
2. Сервер отправляет **три параллельных запроса** к ИИ с `temperature = 0`, `0.7` и `1.2`.
3. Ответы отображаются в трёх столбцах.
4. Сервер отправляет четвёртый запрос, в котором просит ИИ сравнить три ответа по критериям:
   - **точность** — насколько ответ соответствует фактам и вопросу;
   - **креативность** — насколько ответ оригинален и нешаблонен;
   - **разнообразие** — насколько отличаются формулировки и идеи.
5. Итог выводится в блоке «Сравнение и рекомендации»: для каких задач лучше подходит каждая настройка.

## API

### `POST /api/chat`

Принимает JSON:

```json
{ "message": "Текст вопроса" }
```

Возвращает:

```json
{
  "responses": [
    { "temperature": 0, "text": "..." },
    { "temperature": 0.7, "text": "..." },
    { "temperature": 1.2, "text": "..." }
  ],
  "comparison": "Сравнение и рекомендации..."
}
```
