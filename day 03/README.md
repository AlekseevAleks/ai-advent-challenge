# Чат с OpenAI

Локальный сайт для запросов к модели **gpt-5.4-mini** через OpenAI API.

Слева поле задачи, справа — роли экспертов (по одной на строку). Кнопка **Отправить** запускает запросы **по очереди**:

1. простой запрос по введённому тексту;
2. тот же текст с промтом «решай пошагово»;
3. запрос придумать промт для задачи (ответ на экран не выводится);
4. запрос по задаче с этим промтом (промт показывается в блоке ответа);
5. отдельный запрос от каждого эксперта из правого поля.

Под каждым видимым ответом — расход токенов и настройки модели.

Ключ API читается с сервера из файла `api-key.txt` и в браузер не отдаётся.

## Что нужно

- Python 3.9 или новее (дополнительные пакеты не требуются)
- ключ OpenAI в файле `api-key.txt` в корне проекта (одна строка)

## Запуск

```bash
cd "путь/к/проекту"
python3 server.py
```

Сайт откроется по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Порт и модель можно задать переменными окружения:

```bash
PORT=8080 OPENAI_MODEL=gpt-5.4-mini python3 server.py
```
