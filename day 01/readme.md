
# OpenAI API Client

Простой Python скрипт для взаимодействия с OpenAI API через командную строку.

## 📋 Описание

Этот скрипт позволяет отправлять запросы к OpenAI API и получать ответы прямо из терминала. Он автоматически сохраняет ваш API ключ для последующих использований.

### Возможности

- ✅ Автоматическое сохранение API ключа
- ✅ Интерактивный ввод запросов
- ✅ Поддержка модели GPT-5.4-mini
- ✅ Хранение истории запросов (store=True)

### Установка зависимостей
```
bash
pip install openai
```

### 🚀 Использование
Запуск скрипта
```
bash
python script.py
```

### Пример работы
```
bash
$ python script.py

Введите ваш API ключ: sk-... (только при первом запуске)
Ваш вопрос: Напиши приветствие на Python

Ответ: print("Hello, World!")
```
