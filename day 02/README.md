# Чат с OpenAI

Локальный сайт для запросов к модели **gpt-5.4-mini** через OpenAI API.

На странице два столбца:

- **слева** — текст запроса и ответ модели без дополнительных условий;
- **справа** — описание формата ответа, ограничение длины, условие завершения и ответ модели уже с этими условиями.

Кнопка **Отправить** запускает оба запроса. Под каждым ответом показываются расход токенов и настройки модели.

Ключ API читается с сервера из файла `api-key.txt` и в браузер не отдаётся.

## Что нужно

- Python 3.9 или новее (дополнительные пакеты не требуются)
- ключ OpenAI в файле `api-key.txt` в корне проекта (одна строка)

## Запуск

```bash
cd "путь/к/проекту"
python3 server.py
```

Сайт откроется по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Порт и модель можно задать переменными окружения:

```bash
PORT=8080 OPENAI_MODEL=gpt-5.4-mini python3 server.py
```
